실습용 가상 문서다.

## 적용 대상

NFS로 연결한 폴더에서 `df`나 `ls`가 멈추거나, `Stale file handle`, `mount.nfs: Connection timed out`이 나올 때 적용한다.

## 조치 순서

1. `timeout 5 df -h`로 확인한다. 응답이 없으면 NFS 마운트가 멈춘 것이다. `df`를 그냥 실행하면 터미널이 멈추므로 `timeout`을 붙인다.
2. `showmount -e <NFS 서버 주소>`로 NFS 서버가 폴더를 내보내고 있는지 확인한다.
3. `ping -c 3 <NFS 서버 주소>`로 NFS 서버까지 네트워크가 닿는지 확인한다.
4. 서버는 정상인데 멈춰 있으면 `umount -f -l <마운트 경로>`로 연결을 끊는다. 이 폴더를 쓰는 프로세스가 있으면 먼저 담당자에게 알린다.
5. `mount -a`로 다시 연결하고 `timeout 5 df -h`로 정상 응답하는지 확인한다.

## 참고

- 이 문서는 NFS 버전 3을 기준으로 쓴 것이다. 버전 4 이상에서는 `nfsstat -m`으로 실제 연결 방식을 먼저 확인한다.
- `Stale file handle`은 서버 쪽에서 폴더가 다시 만들어졌을 때 생긴다. 이 경우에도 끊고 다시 연결한다.
- `umount -l`은 쓰고 있는 프로세스가 있어도 연결을 끊으므로, 쓰던 작업의 데이터가 유실될 수 있다.
