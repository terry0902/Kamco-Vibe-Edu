실습용 가상 문서다.

## 적용 대상

서버에 접속되지 않거나, `Network is unreachable`, `No route to host`, `Connection timed out` 에러가 나거나, 시스템 로그에 `Link is Down`이 남았을 때 적용한다.

## 조치 순서

1. `ip -br link`로 네트워크 인터페이스가 `UP` 상태인지 확인한다.
2. `ip -br addr`로 주소가 할당되어 있는지, `ip route`로 기본 경로가 있는지 확인한다.
3. 기본 경로의 게이트웨이로 `ping -c 4 <게이트웨이>`를 실행해 내부 통신을 확인한다.
4. `journalctl -k | grep -i "link is"`로 링크가 끊겼다 붙기를 반복하는지 확인한다. 반복하면 케이블과 스위치 포트 점검을 요청한다.
5. 인터페이스가 내려가 있으면 `ip link set <인터페이스> up`으로 올린다. 그래도 복구되지 않으면 선임에게 문의한다.

## 참고

- 내부 통신은 되는데 도메인 접속만 안 되면 `resolvectl status`로 DNS 설정을 확인한다.
- 원격 접속 중에는 사용 중인 인터페이스를 내리지 않는다. 접속이 끊겨 복구할 수 없게 된다.
