실습용 가상 문서다.

## 적용 대상

서버의 CPU 또는 GPU 온도 경보, 서버실 온도 경보가 왔을 때 적용한다.

## 조치 순서

1. `ipmitool sdr type temperature`로 서버 온도를 확인한다.
2. 온도가 90도 미만이면 `ipmitool sdr type fan`으로 팬 상태를 확인하고 10분 동안 지켜본다.
3. 온도가 90도 이상이면 작업을 옮기지 말고 즉시 `shutdown -h now`로 서버를 종료한다.
4. 시설 담당자에게 냉방 점검을 요청한다.
5. 온도가 정상으로 돌아오면 서버를 켜고 작업을 다시 시작한다.

## 참고

- 장비 보호를 서비스 유지보다 우선한다.
- 온도 경보가 하루에 3번 이상 오면 팬 교체를 요청한다.
