실습용 가상 문서다.

## 적용 대상

CPU 또는 GPU 온도 경보가 왔거나, 시스템 로그에 `temperature above threshold`가 남았을 때 적용한다.

## 조치 순서

1. `ipmitool sdr type temperature`로 흡기, CPU, GPU 온도를 확인한다. GPU 서버는 `nvidia-smi`도 함께 확인한다.
2. `ipmitool sdr type fan`으로 멈춘 팬이 있는지 확인한다.
3. 온도가 85도 이상이면 서비스 담당자에게 알리고 작업을 다른 서버로 옮긴다.
4. 작업을 옮긴 뒤 `shutdown -h now`로 서버를 정상 종료한다.
5. 냉각 점검을 요청하고, 점검이 끝나면 서버를 켠 뒤 온도를 다시 확인한다.

## 참고

- 전원을 강제로 차단하지 않는다. 데이터가 손상될 수 있다.
- 같은 랙의 다른 서버도 온도가 높으면 냉방 문제일 수 있으므로 시설 담당자에게 함께 알린다.
